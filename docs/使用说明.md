# 使用说明

## 硬件与约束

FPGA 顶层为 `TD_Project/rtl/top.v`。实际引脚以 `TD_Project/constraints/hx4s20_key_slideshow.adc` 为准，时序以同目录 `.sdc` 为准。

串口屏采用 115200 bit/s、8N1：FPGA 接收为 D14，FPGA 发送为 G11，双方共地。外设 TX 接 FPGA RX，外设 RX 接 FPGA TX。供电连接应遵循板卡及屏的规格。

## 板载操作

| 控件 | 操作 |
|---|---|
| K1 短按 | 普通模式切到下一张图片 |
| K2 短按 | 开启或停止自动轮播 |
| K2 长按约 1 秒后松开 | 普通模式返回上一张图片 |
| K1+K2 长按后松开 | 进入或退出缩略图；在非应急、非设置、非短片模式使用 |
| 缩略图模式 K1/K2 短按 | 移动选框；长按 K2 后松开确认 |
| K3 短按/长按 | 切换亮度、对比度、音量；长按连续调节选中项 |
| SW3 | 显示或退出轮播间隔设置；设置中 K1 加 1 秒，K2 减 1 秒，范围 1～30 秒 |
| SW1 | 开启并循环播放短片；拨回后在帧边界退出并恢复宣教 |
| SW2 | 显示或隐藏音频波形 |
| SW4 | 保持人工应急请求，与触屏请求共同决定应急状态 |
| K4 | 复位当前 FPGA 配置中的播放和加载状态 |

短片期间普通切图与轮播暂停，标题、参数、字幕、波形暂时隐藏，原功能和设置仍保留。人工应急优先于普通播放和短片；全部应急来源解除后，按 SW1 状态恢复宣教或从首帧重新播放短片。

## 目录中的主要模块

- `rtl/filesystem/`：FAT32 扫描、文件流与 BMP 解析、缩放。
- `rtl/framebank/`：预加载、SDRAM 数据通路、帧选择、转场与 CRC 诊断。
- `rtl/video_clip/`：短片装载、循环控制、逐行放大及语音输出。
- `rtl/audio/`、`rtl/hdmi_audio/`：PCM 流、增益、应急混合与 HDMI 音频封装。
- `rtl/control/`、`rtl/uart/`、`rtl/display/`：板载与触屏交互、跨域提交和画面叠加。
- `rtl/base/`：保留的基础驱动、PLL、FIFO、SDRAM 加密 IP 与 HDMI 物理接口。

## 触屏命令示例

命令按文本行发送，以回车结束。包括 `PIC NEXT`、`PIC PREV`、`PLAY ON`、`PLAY OFF`、`SET B HH`、`SET C HH`、`SET V HH`、`TEXT SAFETY FIRST`、`SUB ON`、`SUB OFF`、`EMG ON`、`EMG OFF`。HH 为两位十六进制参数；数值范围、应答与模式限制以 UART 命令解析源码为准。

字幕页先编辑再发送。清空并发送使字幕内容为空白，显示使能仍保留；关闭字幕则隐藏已提交内容。预置汉字由字模显示，动态输入最多 32 个 ASCII 字符。
